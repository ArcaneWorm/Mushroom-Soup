# Mushroom Soup

## Setup Instructions:
Play the WebGL Build: [Mushroom Soup](https://play.unity.com/en/games/76b52737-9190-4b61-9a18-6e222093350d/mushroom-soup-build) 
Or:
1. Download zip file and unzip
2. Open project in Unity
    - Version 2022.3.50f or later
3. Run game in Unity

## Features
- Collect materials: Certain materials can be collected when the player is within range by clicking on the item
- Craft items: Open the crafting menu by pressing "c" and select the type of item you want to craft. Items are craftable when the player has enough materials in their inventory.
- Farming: After crafting the garden bed, a recipe for seeds is unlocked. Plant seeds by placing them in the world and wait for them to grow.
- Enemies: Hostile enemies shoot projectiles at the player. Player health will decrease if they are hit with a projectile, and losing all health results in game over.
- Base building: Place items from inventory to build a base.
- Trash: Drag items from inventory to the trash if items are not wanted / no longer needed.
